# 1. Project

## Website Type

Single-page interactive digital-art portfolio and commission website.

---

# 2. Primary Objective

Build a fast, responsive, visually distinctive one-page website for a digital artist.

The website must accomplish two things simultaneously:

### Portfolio

Showcase the artist's work in an artistic and memorable way.

### Commission

Make it extremely easy for an interested visitor to understand pricing and request a commission.

The website should never feel like a sales landing page.

It is primarily an artist portfolio with a strong commission pathway.

---

# 3. Primary Sections

The website contains exactly four primary sections:

1. Portfolio
2. Pricing
3. Commission / Contact
4. About

Do NOT introduce additional primary navigation sections without explicit approval.

Secondary content may exist inside these sections.
