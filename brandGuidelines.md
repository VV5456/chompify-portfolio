# CHOMPIFY — Brand & Design Guidelines

> This document is the visual and creative source of truth for the Chompify website.
>
> Any visual decision made during development should follow this document unless explicitly overridden by the project owner.

---

# 1. Brand

## Brand Name

CHOMPIFY

## Artist

SAANVI KHORATE

## Brand Descriptor

DIGITAL ART

---

# 2. Brand Personality

Chompify is a personal digital-art brand.

The website should communicate:

- Artistic
- Elegant
- Personal
- Warm
- Creative
- Contemporary
- Premium
- Approachable
- Human

The website should NOT feel:

- Corporate
- Generic
- Like a SaaS product
- Like a standard portfolio template
- Overly futuristic
- Technically complicated
- Cold
- Excessively minimal
- Over-designed

The artwork is always the primary visual focus.

---

# 3. Core Creative Direction

## Digital Gallery Wall

The website should feel like a digital interpretation of a curated art exhibition.

The visitor should feel as though they are exploring a gallery containing Saanvi's work.

However, the website should NOT attempt to become a literal 3D virtual museum.

The preferred approach is a lightweight **2.5D digital gallery**.

The experience should create depth and physicality using:

- Composition
- Layering
- Shadows
- Framing
- Perspective
- Parallax
- Subtle movement
- Typography
- Transitions
- Carefully positioned artwork

The illusion of a physical gallery should come primarily from visual composition rather than heavy 3D technology.

---

# 4. Design Philosophy

## Art First

The artwork is the most important element of the website.

The website should showcase the artist's work rather than showcase the developer's technical abilities.

Every interaction should answer at least one of these questions:

- Does this make the artwork more interesting?
- Does this make the website easier to use?
- Does this help the visitor understand the artist?
- Does this make commissioning easier?

If an interaction does none of these things, it probably should not exist.

---

# 5. Website Structure

The website is a single-page experience.

There are exactly four primary sections:

1. Portfolio
2. Pricing
3. Commission / Contact
4. About

No additional primary navigation sections should be introduced without explicit approval.

Secondary content can exist within these four sections.

---

# 6. Visual Identity

The website should inherit the visual language established by the existing Chompify brand board.

The brand board establishes a warm, editorial, artistic aesthetic.

The primary visual characteristics are:

- Warm cream backgrounds
- Muted blue
- Muted terracotta
- Soft golden yellow
- Deep olive
- Dark brown / charcoal
- Elegant serif typography
- Clean geometric sans-serif typography
- Rich, detailed artwork
- Editorial composition
- Generous whitespace
